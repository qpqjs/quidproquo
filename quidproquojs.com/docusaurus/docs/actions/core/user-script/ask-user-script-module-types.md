# askUserScriptModuleTypes

Returns the type declarations of every module this service lets user scripts import that declared `types` with [defineUserScriptModule](../../../config/core/user-script-module.md). A script editor loads them so a script's imports autocomplete and type check. The declarations are generated by the bundler from each module's TypeScript entry, so they always match the code the service runs.

- **Action type:** `UserScriptActionType.ModuleTypes`

```typescript
import { askUserScriptModuleTypes } from 'quidproquo-core';

export function* askScriptEditorTypes() {
  // [{ moduleName: 'my-app-sdk/v1', declarations: 'export declare const ...' }]
  return yield* askUserScriptModuleTypes();
}
```

## Signature

```typescript
function* askUserScriptModuleTypes(): AskResponse<UserScriptModuleTypes[]>;
```

## Returns

`UserScriptModuleTypes[]`: `{ moduleName, declarations }` for each module with `types`. Modules without `types` are left out. Register each `declarations` under `moduleName` in the editor (for Monaco, as an extra lib at `file:///node_modules/<moduleName>/index.d.ts`).

## Errors

| Error | Cause |
| --- | --- |
| `TypesNotFound` | A declared `types` entry did not load as declarations; the service was not bundled with its types. |

## Related
